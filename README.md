# portfolio-demo

个人项目展示页,GitHub Pages 托管。

## 线上地址

https://lin-wan-fish.github.io/portfolio-demo/

## 本地预览

直接用浏览器打开 `index.html`,或起一个静态服务器:

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署

推送到 `master` 后由 GitHub Pages 自动构建发布。仓库里的 `.nojekyll` 用于跳过 Jekyll 处理。
